How it works

Trustle is played right here, so its board fills in by itself. Wordle, Connections, Krillion and RNGdle live on other sites that don’t let anyone check a score, so this board runs on the honor system: whatever you paste is what goes up. The first result you post for a puzzle is the one that counts, and only today’s puzzles (or yesterday’s) can be posted. RNGdle’s share doesn’t say which day it’s from, so a roll counts for the day you post it.

Results that are hard to believe (Wordle in one guess, a perfect Krillion, a long run of perfect Connections, a top 0.1% RNGdle roll) get a Sus? tag until an admin takes a look. If you think someone’s fibbing, report it. Posting a result earns 100 clicks, once a day for each game, but it’s the same 100 whatever you scored, so there’s nothing to win by cheating except bragging rights.
